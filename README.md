## 👋 About This Repository

This repository is my Python companion to [leetcode-cpp-solutions](https://github.com/nishokcodes/leetcode-cpp-solutions). I use it to practise problem-solving, learn Python, and keep readable solutions with their LeetCode problem links.

## 🎯 Goals

- 🧠 Improve logical thinking and problem-solving.

- 📚 Learn algorithms and data structures.
- 🔁 Compare Python approaches with my C++ solutions where useful.

## 📂 Repository Structure

```text
leetcode-python-solutions/
├── Easy/
│   └── 0001_two_sum.py
```

Solutions are named with the zero-padded LeetCode problem number and a `snake_case` title, for example `0001_two_sum.py`. Each solution includes a link to the problem and its expected `Solution` method.
